**TL;DR**

{% code(title="bash") %}
```bash
cargo install chops-search --locked
```
{% end %}

The wasm engine and browser runtime are embedded in the binary. That is the
only install step: no wasm toolchain, no npm, and nothing to copy by hand.

## Prerequisite

[Rust](https://www.rust-lang.org/tools/install) and cargo:

```sh
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

## Latest unpublished version from GitHub

For features or fixes that haven't reached crates.io yet:

```sh
cargo install --git https://github.com/gitbadger-clan/chops-search --locked chops-search
```

Pin a specific commit with `--rev <sha>` if you want the install reproducible.

## Source build

For contributing or hacking on the engine:

```sh
git clone https://github.com/gitbadger-clan/chops-search.git
cd chops-search
cargo install --path crates/chops-search --locked
```

The workspace has three crates: `chops-search-core` (the engine, compiled to
both native and wasm), `chops-search-wasm` (the wasm bindings), and
`chops-search` (the CLI you just installed). You only ever build the CLI; the
wasm it ships is regenerated by maintainers and verified by CI.

{% aside(kind="note", title="Verify the install") %}
`chops-search --help` lists every subcommand with its defaults stated inline.
Then head to [Getting Started](/tutorials/getting-started/).
{% end %}
